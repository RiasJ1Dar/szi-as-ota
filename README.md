# szi-as-ota

Публічне дзеркало **зашифрованих** інкрементних оновлень програми «СЗІ в АС».

Це не вихідний код програми і не ключі. Тут лише блоби, які клієнт качає по HTTPS.

## Як це влаштовано

| Файл | Що всередині |
|---|---|
| `manifest.szi` | Зашифрований перелік файлів (шляхи, SHA-256, розміри, версія) |
| `blobs/<SHA-256>.bin` | Один файл програми, зашифрований окремо |

Формат блоба: `SZIUKEY1` + IV + AES-256-CBC + HMAC-SHA512 (Encrypt-then-MAC).
Ключ виводиться з секрету виданого `look.key`, не з коду доступу напряму.

- Змінився **1** файл — клієнт качає **1** блоб.
- Змінилось **50** — качає **50**.
- Незмінений файл має той самий SHA-256, блоб уже є, повторно не береться.
- Імена блобів — хеші вмісту, не шляхи.

Розшифровка: виданий `look.key` (на корені носія) + код доступу вкладки ЛООК.
Код і `look.key` у цей репозиторій **не кладуться**.

## Клієнт

У програмі: **Головна → Оновлення програми → З GitHub**.

База:

`https://raw.githubusercontent.com/RiasJ1Dar/szi-as-ota/main`

`gh` на АРМ не потрібен. На АРМ без мережі пакет приносять на носії.

Дані АРМ (`результати`, `look.szi`, `look.key`, `unit.json`) оновлення не чіпає.

## Що тут заборонено

- `look.key`, `look.szi`, `look.json`, будь-які паролі
- відкритий перелік файлів (маніфест теж зашифрований)
- дані АРМ, скріни з ніком або нагородами
- пропатчений `LGPO.exe`
